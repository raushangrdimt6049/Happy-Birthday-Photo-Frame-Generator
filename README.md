# 🎁 Happy Birthday Nandini — Custom Photo Frame

An interactive, responsive digital picture frame web application designed for celebrating a special birthday.

## ✨ Features
- **Authentic Carved Wood Frame**: High-resolution wooden picture frame with multiple frame modes (Wood, Modern Bevel, Frameless).
- **July Birthday Calendar**: Custom July calendar with dove banner, July 11 glossy heart badge, and responsive typography.
- **Romantic Birthday Promise Quote**: Elegant pure HTML/CSS text in *Playfair Display Italic* with generous horizontal word spacing, emojis, and sparkle accents.
- **6-Photo Collage Gallery Grid**: Curated grid with hover micro-animations and click-to-zoom Lightbox modal preview.
- **Wedding Calligraphy Greeting**: Flowing *Great Vibes* script at the footer centered between crystal glass butterflies.
- **Ambient Lighting**: Atmospheric gallery spotlight toggle and screen fitting controls.
- **Responsive Container Queries**: Scales proportionally on desktop monitors, laptops, and mobile devices using CSS container units (`cqw`).

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/<your-username>/<repo-name>.git
   ```
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari).
